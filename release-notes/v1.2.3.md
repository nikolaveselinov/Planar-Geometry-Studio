## A simpler workspace

A restrained desktop layout puts the configuration and results first, with standard controls, a neutral dark palette, and clearer setup screens.

## A clearer starting point

Start with a focused triangle-and-medians example, then explore the full construction catalog from **Constructions** above the editor or **Ctrl+K**. Search by name or description, filter by the object created, inspect argument types, copy an example call, or enable a tool for generation.

The starter configuration stays short; the complete reference lives in the app.

## Setup and updates

Studio Setup can install the optional TeX/PDF tools used to draw figures. Choose **Start studio** to begin with generation and proofs, or complete drawing setup immediately. Existing tools are reused. Updates are checked in the background at launch; manage this in **Help → Studio Setup**.

macOS installation now consistently places Studio in **Applications**, including when a portable copy exists elsewhere. Your saved configurations and runs remain separate from the application.

## Optional verification

All signature files, public keys, fingerprints, and verification instructions are in the single [verification archive](https://github.com/nikolaveselinov/Planar-Geometry-Studio/releases/download/v1.2.3/PlanarGeometryStudio-v1.2.3-verification.zip). `SHA256SUMS` covers the downloads. These files are optional; operating-system security warnings may still appear.
