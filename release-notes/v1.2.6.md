This release fixes a drawing-tool startup crash that could prevent figures from being generated in both installed and portable copies. Figure generation now also includes the tool’s error details when something goes wrong.

If you use **1.2.5**, leave automatic downloads enabled and reopen Studio to receive this update, then choose **Restart to update** when it is ready. Versions before 1.2.5 need one manual upgrade to gain automatic updates. Your configurations, runs, and drawing tools are preserved.

## Setup and updates

Studio Setup can install the optional TeX/PDF tools used to draw figures. Choose **Start studio** to begin with generation and proofs, or complete drawing setup immediately. Existing tools are reused. Updates are checked and downloaded in the background at launch; manage checks and downloads in **Help → Studio Setup**.

Your saved configurations and runs remain separate from the application.

## Optional verification

All signature files, public keys, fingerprints, and verification instructions are in the single [verification archive](https://github.com/nikolaveselinov/Planar-Geometry-Studio/releases/download/v1.2.6/PlanarGeometryStudio-v1.2.6-verification.zip). `SHA256SUMS` covers the downloads. These files are optional; operating-system security warnings may still appear.
