Studio can now keep itself up to date. New stable versions download in the background, are verified, and open on your next launch. Choose **Restart to update** to switch immediately, with the normal save prompt for unsaved input.

Updates work for installed and portable copies without administrator rights. Your drawing tools, preferences, configurations, and runs are reused. The installed copy stays available for recovery. Downloads still contain the full app package; no installer wizard is needed for subsequent updates.

**One-time upgrade:** versions before 1.2.5 need one manual upgrade to gain this updater. Automatic updates apply to releases after that upgrade.

## Setup and updates

Studio Setup can install the optional TeX/PDF tools used to draw figures. Choose **Start studio** to begin with generation and proofs, or complete drawing setup immediately. Existing tools are reused. Updates are checked and downloaded in the background at launch; manage checks and downloads in **Help → Studio Setup**.

Your saved configurations and runs remain separate from the application.

## Optional verification

All signature files, public keys, fingerprints, and verification instructions are in the single [verification archive](https://github.com/nikolaveselinov/Planar-Geometry-Studio/releases/download/v1.2.5/PlanarGeometryStudio-v1.2.5-verification.zip). `SHA256SUMS` covers the downloads. These files are optional; operating-system security warnings may still appear.
