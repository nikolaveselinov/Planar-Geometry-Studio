## Install, or keep it portable

Native installers are now available for Windows, macOS, and Linux on Intel / AMD 64-bit and ARM64. The existing ZIP and tar.gz archives remain available for users who prefer to extract and run the app, including on computers without administrator rights.

## Guided first launch

Studio Setup helps prepare optional figure-rendering tools, reuses existing TeX installations, and offers automatic dependency installation. Generation and proofs work with the bundled runtime even if you skip drawing setup.

Studio now checks for updates at launch and links to the matching download. You can disable this in Help → Studio Setup. Installers add the usual application shortcuts and preserve your configurations and results when upgrading or uninstalling.
