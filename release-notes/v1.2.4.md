Choose several generation tools in one visit to **Constructions** (**Ctrl+K**). Compact checkboxes show which tools your configuration already uses and let you enable or disable them without closing the browser.

Selections stay intact while searching or filtering. Changes appear in your input immediately; initial definitions and other settings stay intact. Save your configuration to keep your choices.

## Setup and updates

Studio Setup can install the optional TeX/PDF tools used to draw figures. Choose **Start studio** to begin with generation and proofs, or complete drawing setup immediately. Existing tools are reused. Updates are checked in the background at launch; manage this in **Help → Studio Setup**.

Your saved configurations and runs remain separate from the application.

## Optional verification

All signature files, public keys, fingerprints, and verification instructions are in the single [verification archive](https://github.com/nikolaveselinov/Planar-Geometry-Studio/releases/download/v1.2.4/PlanarGeometryStudio-v1.2.4-verification.zip). `SHA256SUMS` covers the downloads. These files are optional; operating-system security warnings may still appear.
